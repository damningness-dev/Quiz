📶 다른 기기와 동기화

이 기기의 주소를 불러오는 중...

휴대폰/PC 등 서로 다른 기기에서 각자 문제를 등록했다면, 목록이 서로 달라져 있을 수 있습니다. 같은 Wi-Fi에 두 기기 모두 이 화면(서버)이 켜져 있는 상태에서, 아래에 상대 기기의 주소를 입력하고 동기화하면 양쪽에 없는 문제를 서로 채워 넣어 둘 다 합친 목록으로 맞춰줍니다 (한쪽에서 한 번만 눌러도 양쪽 다 반영됩니다).

1. 유튜브에서 소리 찾기

검색이 안 되면 서버에 YOUTUBE_API_KEY가 설정되어 있지 않은 것입니다. 이 경우 아래 "유튜브 URL 직접 입력"에 영상 주소를 붙여넣어 사용하세요.

2. 문제 등록

재생 구간은 따로 지정하지 않아도 됩니다 — 게임 진행 중 영상 전체에서 매번 무작위 구간을 골라 들려줍니다.

3. 여러 문제 한번에 가져오기

Claude가 만들어준 JSON 목록을 아래에 그대로 붙여넣고 "가져오기"를 누르면 한 번에 등록됩니다. (git을 따로 만질 필요 없이 이 화면에서 바로 반영돼요)

등록된 문제 목록 (0개)

표의 칸을 바로 클릭해서 고친 뒤(엑셀처럼 여러 칸을 한꺼번에), "변경사항 저장"을 누르면 한 번에 반영됩니다. 영상(유튜브 URL) 변경은 "영상변경" 버튼으로 위 등록 폼을 사용하세요.
