# 🎲 보드게임 사운드 퀴즈쇼

같은 Wi-Fi 안에서 PC(진행자)와 여러 명의 모바일(참가자)이 함께 즐기는 로컬 사운드 퀴즈 프로그램입니다.
보드게임 소리를 유튜브에서 찾아 문제로 등록하고, 참가자들이 부저를 눌러 정답을 맞히는 퀴즈쇼 형식입니다.

- 사운드는 다운로드/저장하지 않고 유튜브 임베드 플레이어로 그 자리에서 스트리밍 재생합니다.
- 서버, 진행자 화면, 참가자 화면 모두 브라우저로 동작하지만, **인터넷의 다른 사람은 접속할 수 없는 완전히 로컬(같은 Wi-Fi 안)** 프로그램입니다.

## 1. 설치

[Node.js](https://nodejs.org) 18 버전 이상이 설치되어 있어야 합니다.

```bash
npm install
```

## 2. (선택) 유튜브 자동 검색 설정

문제 등록 화면에서 유튜브를 검색어로 바로 찾고 싶다면 API 키가 필요합니다.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들고 **YouTube Data API v3**를 활성화합니다.
2. API 키를 발급받습니다.
3. 프로젝트 루트에 `.env` 파일을 만들고 아래처럼 입력합니다. (`.env.example` 참고)

```
YOUTUBE_API_KEY=발급받은키
```

> API 키가 없어도 됩니다! 유튜브에서 직접 영상을 찾은 뒤, 문제 등록 화면의 "유튜브 URL 직접 입력"란에
> 주소(`https://www.youtube.com/watch?v=...`)를 붙여넣으면 검색 없이도 그대로 사용할 수 있습니다.

## 3. 실행

```bash
npm start
```

터미널에 아래와 같은 접속 주소가 출력됩니다.

- 문제 관리(관리자): `http://localhost:3000/admin.html`
- 진행자 화면(PC/TV): `http://localhost:3000/host.html`
- 참가자 입장(모바일): `http://<이 PC의 로컬 IP>:3000/player.html`

## 4. 사용 방법

1. **문제 등록** (`admin.html`): 보드게임 이름(정답)을 입력하고, 유튜브에서 소리를 검색하거나 URL을 붙여넣습니다.
   재생 구간(시작~종료 초)을 지정하고 "미리듣기"로 확인한 뒤 저장합니다.
2. **참가자 입장** (`player.html`): 참가자들은 진행자 PC와 같은 Wi-Fi에 연결된 상태에서, 진행자 화면에 표시되는
   주소로 접속해 닉네임을 입력하고 입장합니다. (모바일 카메라로 QR을 찍고 싶다면 위 주소를 QR 생성기로 변환해 사용하세요.)
3. **진행** (`host.html`): 진행자는 PC/TV 화면에서 문제 목록 중 하나를 눌러 소리를 재생합니다.
   참가자 중 누군가 먼저 부저를 누르면 화면에 표시되고, 진행자가 정답/오답을 판정합니다.
   - 정답 처리: 점수 +1, 정답 공개
   - 오답 처리: 그 참가자는 이번 문제에서 제외되고, 다른 참가자가 다시 부저를 누를 수 있습니다.
   - 정답 공개(패스): 아무도 못 맞혔을 때 정답만 공개
   - 부저 초기화: 판정 없이 부저 상태만 리셋

## 문제 데이터

등록한 문제는 `data/questions.json`에 저장되어 프로그램을 껐다 켜도 유지됩니다.

## 참고: 모바일에서 접속이 안 될 때

- 참가자의 휴대폰이 진행자 PC와 **같은 Wi-Fi**에 연결되어 있는지 확인하세요.
- Windows 방화벽이 Node.js의 포트(기본 3000)를 막고 있을 수 있습니다. 방화벽 허용 팝업이 뜨면 "허용"을 눌러주세요.
- 회사/카페 Wi-Fi 등 기기 간 통신이 차단된 네트워크에서는 접속이 안 될 수 있습니다. 개인 Wi-Fi 공유기나 휴대폰 핫스팟을 권장합니다.
