# 🎲 보드게임 사운드 퀴즈쇼

같은 Wi-Fi 안에서 PC(진행자)와 여러 명의 모바일(참가자)이 함께 즐기는 로컬 사운드 퀴즈 프로그램입니다.
보드게임 소리를 유튜브에서 찾아 문제로 등록하고, 참가자들이 부저를 눌러 정답을 맞히는 퀴즈쇼 형식입니다.

- 사운드는 다운로드/저장하지 않고 유튜브 임베드 플레이어로 그 자리에서 스트리밍 재생합니다.
- 서버, 진행자 화면, 참가자 화면 모두 브라우저로 동작하지만, **인터넷의 다른 사람은 접속할 수 없는 완전히 로컬(같은 Wi-Fi 안)** 프로그램입니다.
- 서버는 보통 PC에서 실행하지만, PC 없이 **안드로이드 휴대폰만으로 서버를 실행**할 수도 있습니다 → [5. PC 없이 안드로이드에서 직접 서버 실행하기](#5-선택-pc-없이-안드로이드에서-직접-서버-실행하기)

## 1. 설치

[Node.js](https://nodejs.org) 18 버전 이상이 설치되어 있어야 합니다.

```bash
npm install
```

## 2. (선택) 유튜브 자동 검색 설정

문제 등록 화면에서 유튜브를 검색어로 바로 찾고 싶다면 API 키가 필요합니다.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들고 **YouTube Data API v3**를 활성화합니다.
2. API 키를 발급받습니다.
3. 프로젝트 루트에 `.env` 파일을 만들고 아래처럼 입력합니다. (`.env.example` 참고)

```
YOUTUBE_API_KEY=발급받은키
```

> API 키가 없어도 됩니다! 유튜브에서 직접 영상을 찾은 뒤, 문제 등록 화면의 "유튜브 URL 직접 입력"란에
> 주소(`https://www.youtube.com/watch?v=...`)를 붙여넣으면 검색 없이도 그대로 사용할 수 있습니다.

## 3. 실행

```bash
npm start
```

터미널에 아래와 같은 접속 주소가 출력됩니다.

- 문제 관리(관리자): `http://localhost:3000/admin.html`
- 진행자 화면(PC/TV): `http://localhost:3000/host.html`
- 참가자 입장(모바일): `http://<이 PC의 로컬 IP>:3000/player.html`

## 4. 사용 방법

1. **문제 등록** (`admin.html`): 보드게임 이름(정답)을 입력하고, 유튜브에서 소리를 검색하거나 URL을 붙여넣습니다.
   재생 구간(시작~종료 초)을 지정하고 "미리듣기"로 확인한 뒤 저장합니다.
2. **참가자 입장** (`player.html`): 참가자들은 진행자 PC와 같은 Wi-Fi에 연결된 상태에서, 진행자 화면에 표시되는
   주소로 접속해 닉네임을 입력하고 입장합니다. (모바일 카메라로 QR을 찍고 싶다면 위 주소를 QR 생성기로 변환해 사용하세요.)
3. **진행** (`host.html`): 진행자는 PC/TV 화면에서 문제 목록 중 하나를 눌러 소리를 재생합니다.
   참가자 중 누군가 먼저 부저를 누르면 화면에 표시되고, 진행자가 정답/오답을 판정합니다.
   - 정답 처리: 점수 +1, 정답 공개
   - 오답 처리: 그 참가자는 이번 문제에서 제외되고, 다른 참가자가 다시 부저를 누를 수 있습니다.
   - 정답 공개(패스): 아무도 못 맞혔을 때 정답만 공개
   - 부저 초기화: 판정 없이 부저 상태만 리셋

## 5. (선택) PC 없이 안드로이드에서 직접 서버 실행하기

PC가 없어도 안드로이드 휴대폰 자체를 서버로 써서 똑같이 진행할 수 있습니다. **[Termux](https://f-droid.org/packages/com.termux/)** 라는 터미널 앱으로 휴대폰 안에서 Node.js를 직접 돌리는 방식입니다.
(PC로 실행하는 방법은 위 1~4번 그대로 유지되고, 이 방법은 PC 없이 진행하고 싶을 때 추가로 쓰는 방법입니다.)

> ⚠️ Play 스토어의 Termux는 업데이트가 중단되어 제대로 동작하지 않을 수 있습니다. 반드시 **F-Droid** 버전을 설치하세요.
> ([F-Droid 앱](https://f-droid.org/) 설치 후 그 안에서 Termux 검색 · 설치, 또는 [Termux GitHub 릴리스](https://github.com/termux/termux-app/releases)에서 apk 직접 설치)

### 5-1. Termux 준비

Termux를 열고 아래 명령을 순서대로 입력합니다.

```bash
pkg update && pkg upgrade
pkg install nodejs git
```

### 5-2. 프로젝트 내려받기 & 설치

```bash
git clone https://github.com/damningness-dev/Quiz.git
cd Quiz
npm install
```

(선택) 유튜브 자동 검색을 쓰려면 `.env` 파일을 만들어 키를 넣습니다.

```bash
cp .env.example .env
nano .env   # YOUTUBE_API_KEY=발급받은키 입력 후 Ctrl+O, Enter, Ctrl+X로 저장
```

### 5-3. 서버 실행

```bash
npm start
```

PC 버전과 완전히 동일하게 접속 주소가 출력됩니다. 이제 **이 휴대폰이 서버**이므로, 다른 사람들은 이 휴대폰과 같은 Wi-Fi에 연결한 뒤 이 휴대폰의 로컬 IP로 접속하면 됩니다.

- 진행자 화면도 이 휴대폰(또는 같은 Wi-Fi의 다른 PC/휴대폰)에서 `http://<이 휴대폰의 IP>:3000/host.html`로 접속
- 참가자는 `http://<이 휴대폰의 IP>:3000/player.html`로 접속
- 휴대폰의 IP는 **설정 → Wi-Fi → 연결된 네트워크 정보**에서 확인하거나, Termux에서 아래 명령으로 확인할 수 있습니다.

```bash
ip addr show wlan0 | grep "inet "
```

### 5-4. 서버가 도중에 꺼지는 것 방지하기

안드로이드는 배터리 절약을 위해 백그라운드 앱을 종료시키는 경우가 많습니다. 진행 중 서버가 끊기지 않도록:

- **Termux 앱을 화면에 계속 띄워둔 채로 진행**하거나, 화면을 꺼야 한다면 아래 명령으로 절전으로 인한 종료를 방지하세요.

  ```bash
  termux-wake-lock
  ```

- 휴대폰 설정에서 Termux 앱의 **배터리 사용량 제한을 "제한 없음"** 으로 바꿔두면 더 안정적입니다.
- `Ctrl+C`로 서버를 끄거나 Termux 앱을 완전히 종료하면 서버도 함께 꺼집니다.

## 문제 데이터

등록한 문제는 `data/questions.json`에 저장되어 프로그램을 껐다 켜도 유지됩니다.

## 참고: 모바일에서 접속이 안 될 때

- 참가자의 휴대폰이 진행자 PC와 **같은 Wi-Fi**에 연결되어 있는지 확인하세요.
- Windows 방화벽이 Node.js의 포트(기본 3000)를 막고 있을 수 있습니다. 방화벽 허용 팝업이 뜨면 "허용"을 눌러주세요.
- 회사/카페 Wi-Fi 등 기기 간 통신이 차단된 네트워크에서는 접속이 안 될 수 있습니다. 개인 Wi-Fi 공유기나 휴대폰 핫스팟을 권장합니다.
