# 🎲 보드게임 사운드 퀴즈쇼

같은 Wi-Fi 안에서 PC(진행자)와 여러 명의 모바일(참가자)이 함께 즐기는 로컬 사운드 퀴즈 프로그램입니다.
보드게임 소리를 유튜브에서 찾아 문제로 등록하고, 참가자들이 부저를 눌러 정답을 맞히는 퀴즈쇼 형식입니다.

- 사운드는 다운로드/저장하지 않고 유튜브 임베드 플레이어로 그 자리에서 스트리밍 재생합니다.
- 서버, 진행자 화면, 참가자 화면 모두 브라우저로 동작하지만, **인터넷의 다른 사람은 접속할 수 없는 완전히 로컬(같은 Wi-Fi 안)** 프로그램입니다.
- 서버는 보통 PC에서 실행하지만, PC 없이 **안드로이드 휴대폰만으로 서버를 실행**할 수도 있습니다 → [5. PC 없이 안드로이드에서 직접 서버 실행하기](#5-선택-pc-없이-안드로이드에서-직접-서버-실행하기)

## 1. 설치

[Node.js](https://nodejs.org) 18 버전 이상이 설치되어 있어야 합니다.

```bash
npm install
```

## 2. (선택) 유튜브 자동 검색 설정

문제 등록 화면에서 유튜브를 검색어로 바로 찾고 싶다면 API 키가 필요합니다.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들고 **YouTube Data API v3**를 활성화합니다.
2. API 키를 발급받습니다.
3. 프로젝트 루트에 `.env` 파일을 만들고 아래처럼 입력합니다. (`.env.example` 참고)

```
YOUTUBE_API_KEY=발급받은키
```

> API 키가 없어도 됩니다! 유튜브에서 직접 영상을 찾은 뒤, 문제 등록 화면의 "유튜브 URL 직접 입력"란에
> 주소(`https://www.youtube.com/watch?v=...`)를 붙여넣으면 검색 없이도 그대로 사용할 수 있습니다.

## 3. 실행

```bash
npm start
```

터미널에 아래와 같은 접속 주소가 출력됩니다.

- 문제 관리(관리자): `http://localhost:3000/admin.html`
- 진행자 화면(PC/TV): `http://localhost:3000/host.html`
- 참가자 입장(모바일): `http://<이 PC의 로컬 IP>:3000/player.html`

## 4. 사용 방법

1. **문제 등록** (`admin.html`): 보드게임 이름(정답)을 입력하고, 유튜브에서 소리를 검색하거나 URL을 붙여넣습니다.
   "미리듣기"로 확인한 뒤 저장합니다 (재생 구간은 따로 지정하지 않아도 게임 진행 중 영상 전체에서
   매번 무작위 구간을 골라 들려줍니다). 등록된 문제 목록 표에서 칸을 바로 클릭해 카테고리/연도/정답/메모를
   엑셀처럼 고치고 "변경사항 저장"으로 한 번에 반영할 수 있습니다. `admin.html`은 진행자 화면(`host.html`)과
   **같은 서버**이므로, 여기서 저장하면 진행자 화면에도 바로 반영됩니다(다시 켤 필요 없음).
2. **참가자 입장** (`player.html`): 참가자들은 진행자 PC와 같은 Wi-Fi에 연결된 상태에서, 진행자 화면에 표시되는
   주소로 접속해 닉네임을 입력하고 입장합니다. (모바일 카메라로 QR을 찍고 싶다면 위 주소를 QR 생성기로 변환해 사용하세요.)
3. **진행** (`host.html`): 진행자는 PC/TV 화면에서 문제 목록 중 하나를 눌러 소리를 재생합니다.
   참가자 중 누군가 먼저 부저를 누르면 화면에 표시되고, 진행자가 정답/오답을 판정합니다.
   - 정답 처리: 점수 +1, 정답 공개
   - 오답 처리: 그 참가자는 이번 문제에서 제외되고, 다른 참가자가 다시 부저를 누를 수 있습니다.
   - 정답 공개(패스): 아무도 못 맞혔을 때 정답만 공개
   - 부저 초기화: 판정 없이 부저 상태만 리셋

## 5. (선택) PC 없이 안드로이드에서 직접 서버 실행하기

PC가 없어도 안드로이드 휴대폰 자체를 서버로 써서 똑같이 진행할 수 있습니다. **[Termux](https://f-droid.org/packages/com.termux/)** 라는 터미널 앱으로 휴대폰 안에서 Node.js를 직접 돌리는 방식입니다.
(PC로 실행하는 방법은 위 1~4번 그대로 유지되고, 이 방법은 PC 없이 진행하고 싶을 때 추가로 쓰는 방법입니다.)

> ⚠️ Play 스토어의 Termux는 업데이트가 중단되어 제대로 동작하지 않을 수 있습니다. 반드시 **F-Droid** 버전을 설치하세요.
> ([F-Droid 앱](https://f-droid.org/) 설치 후 그 안에서 Termux 검색 · 설치, 또는 [Termux GitHub 릴리스](https://github.com/termux/termux-app/releases)에서 apk 직접 설치)

### 5-1. Termux 준비

Termux를 열고 아래 명령을 순서대로 입력합니다.

```bash
pkg update && pkg upgrade
pkg install nodejs git
```

### 5-2. 프로젝트 내려받기 & 설치

```bash
git clone https://github.com/damningness-dev/Quiz.git
cd Quiz
npm install
```

(선택) 유튜브 자동 검색을 쓰려면 `.env` 파일을 만들어 키를 넣습니다.

```bash
cp .env.example .env
nano .env   # YOUTUBE_API_KEY=발급받은키 입력 후 Ctrl+O, Enter, Ctrl+X로 저장
```

### 5-3. 서버 실행

```bash
npm start
```

PC 버전과 완전히 동일하게 접속 주소가 출력됩니다. 이제 **이 휴대폰이 서버**이므로, 다른 사람들은 이 휴대폰과 같은 Wi-Fi에 연결한 뒤 이 휴대폰의 로컬 IP로 접속하면 됩니다.

- 진행자 화면도 이 휴대폰(또는 같은 Wi-Fi의 다른 PC/휴대폰)에서 `http://<이 휴대폰의 IP>:3000/host.html`로 접속
- 참가자는 `http://<이 휴대폰의 IP>:3000/player.html`로 접속
- 휴대폰의 IP는 **설정 → Wi-Fi → 연결된 네트워크 정보**에서 확인하거나, Termux에서 아래 명령으로 확인할 수 있습니다.

```bash
ip addr show wlan0 | grep "inet "
```

### 5-4. 서버가 도중에 꺼지는 것 방지하기

안드로이드는 배터리 절약을 위해 백그라운드로 돌아가는 프로세스를 강제 종료하는 경우가 많습니다 (기종에 따라 "배터리 사용량 제한: 없음"으로 해둬도 꺼지는 경우가 있습니다). 그래서 이 프로그램은 **서버를 포그라운드로 실행**하도록 되어 있습니다 — 서버를 실행한 Termux 창을 진행 중에 그대로 켜둬야 합니다.

- 서버를 실행한 뒤 **Termux 앱을 완전히 종료(최근 앱 목록에서 스와이프)하지만 않으면** 됩니다. 화면을 잠그는 건 괜찮습니다.
- 화면을 꺼도 서버가 끊기지 않도록 절전 방지를 걸 수 있습니다 (아래 5-5의 스크립트에는 이미 포함되어 있습니다).

  ```bash
  termux-wake-lock
  ```

- 그래도 자꾸 꺼진다면, 표준 배터리 사용량 제한과는 별개로 제조사가 자체적으로 두는 절전 관리(예: 삼성 "절전 앱 관리", 샤오미/오포/비보의 "자동 실행 관리" 등)에서 Termux를 예외로 등록해보세요.
- `Ctrl+C`를 누르거나 Termux 앱을 완전히 종료하면 서버도 함께 꺼집니다.

### 5-5. 홈 화면 위젯으로 시작/중지 편하게 하기

매번 `cd ~/Quiz && node server/index.js`를 직접 치지 않아도, 홈 화면 아이콘(위젯)으로 좀 더 편하게 켜고 끌 수 있습니다.
저장소에 준비된 스크립트(`termux/start-server.sh`, `termux/stop-server.sh`, `termux/status-server.sh`)를 사용합니다.

> ⚠️ "시작" 아이콘을 누르면 그 Termux 창에서 서버가 실행된 채로 유지됩니다. 5-4에서 설명한 것처럼 **진행 중에는 이 창을 닫지 마세요.** "중지" 아이콘은 어디서 눌러도 실행 중인 서버를 찾아 꺼줍니다.

1. F-Droid에서 **Termux:Widget** 앱을 추가로 설치합니다. (Termux 본체와 같은 출처인 F-Droid 버전이어야 정상 동작합니다)
2. Termux에서 최신 스크립트를 받고, 단축 스크립트 폴더에 복사해 넣습니다. (이전에 이미 복사해두셨다면 최신 버전으로 덮어쓰기 위해 다시 실행해주세요.)

   ```bash
   cd ~/Quiz && git pull
   mkdir -p ~/.shortcuts
   cp ~/Quiz/termux/start-server.sh ~/.shortcuts/"퀴즈 서버 시작"
   cp ~/Quiz/termux/stop-server.sh ~/.shortcuts/"퀴즈 서버 중지"
   cp ~/Quiz/termux/status-server.sh ~/.shortcuts/"퀴즈 서버 상태"
   chmod +x ~/.shortcuts/*
   ```

3. 휴대폰 홈 화면의 빈 곳을 길게 눌러 **위젯 추가** → **Termux:Widget** 선택 → 홈 화면에 배치합니다.
4. "퀴즈 서버 시작" 아이콘을 탭하면 서버 콘솔이 뜬 채로 유지됩니다. 진행이 끝나면 "퀴즈 서버 중지" 아이콘을 탭하거나, 그 창에서 `Ctrl+C`를 누르세요.
5. "퀴즈 서버 상태" 아이콘으로 지금 서버가 켜져 있는지 바로 확인할 수 있습니다.

> 실행 결과를 토스트 알림으로도 보고 싶다면 F-Droid에서 **Termux:API** 앱을 추가로 설치하고 Termux에서 `pkg install termux-api`를 실행하세요. 없어도 정상 동작합니다.
> 위젯을 눌러도 아무 반응이 없다면 Termux에서 `echo "allow-external-apps = true" >> ~/.termux/termux.properties && termux-reload-settings`를 실행한 뒤 재부팅해보세요.

주의사항:
- 스크립트는 프로젝트가 `~/Quiz`에 clone되어 있다고 가정합니다. 다른 경로를 썼다면 스크립트 안의 `PROJECT_DIR` 값을 수정하세요.
- 서버 로그는 실행 중인 Termux 창에 그대로 출력됩니다 (별도 로그 파일 없음).

### 5-6. `git pull` 하면 서버 자동 재시작하기

새 코드/데이터를 받을 때마다 서버를 수동으로 껐다 켤 필요 없이, `git pull`만 치면 자동으로 최신 코드로 재시작되도록 설정할 수 있습니다. git의 "post-merge 훅" 기능을 이용합니다 (실제로 새 커밋을 받아왔을 때만 실행되고, "Already up to date"면 아무 일도 안 일어납니다).

**최초 1회만 설정하면 됩니다.**

```bash
cd ~/Quiz
ln -sf ../../termux/post-merge-hook.sh .git/hooks/post-merge
chmod +x termux/post-merge-hook.sh .git/hooks/post-merge
```

이후로는 그냥 이렇게만 하면 됩니다.

```bash
git pull
```

새 내용이 있으면, pull이 끝나자마자 자동으로 기존 서버를 끄고 새 코드로 다시 시작합니다 (이 터미널 창이 서버 콘솔로 바뀝니다 — 5-4처럼 진행 중엔 닫지 마세요). 받아올 새 내용이 없으면(`Already up to date`) 평소처럼 그냥 끝납니다.

## 문제 데이터

등록한 문제는 `data/questions.json`에 저장되어 프로그램을 껐다 켜도 유지됩니다.

## 윈도우 실행 파일(.exe)로 배포하기

참가자용 PC에 Node.js를 따로 설치하지 않아도 되도록, Node 런타임까지 통째로 담은 단일 실행 파일(.exe)을 만들 수 있습니다.

```bash
npm run build:win
```

`dist/QuizServer.exe`와 `dist/data/questions.json`(현재 등록된 문제로 초기화됨)이 만들어집니다.
윈도우 PC로 옮길 때는 **`QuizServer.exe`와 `data` 폴더를 같은 위치에 함께** 두세요 (문제 데이터를 exe 옆의
`data/questions.json`에서 읽고 쓰기 때문입니다). `.env`가 필요하면(유튜브 자동 검색 키) `dist/.env.example`을
참고해 `.env`로 이름을 바꿔 같은 위치에 두면 됩니다.

사용법은 기존과 동일합니다 — `QuizServer.exe`를 더블클릭하면 콘솔 창에 접속 주소가 뜨고, 그 창을 열어둔 채로
브라우저에서 `host.html`(진행자) / `player.html`(참가자) / `admin.html`(문제 관리)에 접속하면 됩니다.
셋 다 같은 서버이므로 `admin.html`에서 문제를 등록/수정하면 `host.html`에도 바로 반영됩니다.
방화벽 허용 팝업이 뜨면 허용해주세요.

> 이 프로젝트를 다시 빌드하지 않고 exe만 새로 받고 싶다면, `dist` 폴더를 통째로 압축해서 옮기면 됩니다.
> `data` 폴더는 실행할 때마다 그 자리의 `questions.json`을 그대로 사용하므로, 이미 배포한 exe 옆의
> `data` 폴더에 있는 문제들은 exe만 새로 교체해도 그대로 유지됩니다.

## 서버 없이(`npm start` 없이) PC에서 문제 등록하기

평소처럼 `admin.html`에서 등록하려면 서버가 켜져 있어야 하지만, 서버를 켜지 않고도
터미널에서 바로 `data/questions.json`에 문제를 추가할 수 있는 대화형 도구가 있습니다.

```bash
npm run add-question
```

`.env`에 `YOUTUBE_API_KEY`가 설정되어 있으면(2번 항목 참고) 먼저 유튜브 검색어를 물어보고,
검색 결과 목록에서 번호로 하나를 고르면 그 영상으로 문제가 등록됩니다 (검색어를 비워두고
Enter만 누르면 URL을 직접 입력하는 방식으로 넘어갑니다). API 키가 없으면 바로 URL 직접 입력
단계로 시작합니다. 영상을 고른 뒤에는 이름(정답, 검색한 영상 제목이 기본값으로 제안됨),
카테고리, 연도, 메모를 순서대로 물어보고, 한 문제씩 입력할 때마다 바로 파일에 저장합니다.
계속 등록할지 물어보므로 여러 문제를 이어서 등록할 수 있고, 중간에 `Ctrl+C`로 중단해도
그때까지 등록한 내용은 남습니다.

> ⚠️ 이 도구는 서버 없이 파일에 직접 쓰기 때문에, **이미 켜져 있는 `QuizServer.exe`(진행자 화면)에는
> 바로 반영되지 않습니다.** 등록을 마친 뒤 `QuizServer.exe`를 새로 켜거나 다시 시작해야 반영됩니다.
> 진행 중인 서버에 바로 반영되길 원한다면 서버를 이미 켜둔 상태에서 브라우저로 `admin.html`에
> 접속해 등록하세요 (위 4번 항목 참고).

> 참고: `data/questions.json`은 그냥 JSON 파일이라 텍스트 에디터로 직접 열어서 고쳐도 됩니다.
> 형식은 파일 안의 기존 항목을 참고하세요 (`id`, `category`, `year`, `title`, `videoId`, `start`, `end`, `note`).

### Node.js도 설치하지 않은 PC라면: 문제 등록 전용 exe

Node.js조차 설치하고 싶지 않다면, 위 `npm run add-question`과 완전히 같은 기능을 하는
전용 exe를 만들 수 있습니다. 서버(포트, 네트워크)를 전혀 쓰지 않으므로 방화벽/포트 충돌과
무관하게 동작합니다.

```bash
npm run build:win:add-question
```

`dist/AddQuestion.exe`가 만들어집니다. `dist/data/questions.json`과 같은 위치에 두고
더블클릭하면 콘솔 창이 뜨면서 바로 문제 등록 질문이 시작됩니다. 진행자 화면용 `QuizServer.exe`와
같은 폴더에 두면 `data` 폴더를 공유하므로, `AddQuestion.exe`로 등록한 문제가 (위와 마찬가지로)
`QuizServer.exe`를 다시 켤 때 반영됩니다.

> 텍스트 질문 대신 검색 결과 썸네일과 표를 보면서 브라우저로 관리하고 싶다면, 이 exe를 따로 만들
> 필요 없이 **`QuizServer.exe`를 켜고 `admin.html`에 접속**하면 됩니다 (위 "윈도우 실행 파일로
> 배포하기" 참고). 진행자 화면과 같은 서버라 저장하는 즉시 반영되는 것이 장점입니다.

## 문제를 대량으로 채우기 (곡 목록 → 유튜브 자동 매칭)

Claude가 조사해준 "가수/곡명" 목록(JSON)을 유튜브 링크까지 자동으로 찾아 한 번에 등록하는 스크립트입니다. `admin.html`의 "일괄 가져오기"와 다르게, 이 스크립트는 videoId를 직접 찾아줘야 할 때(즉 아직 유튜브 링크를 모르는 곡 목록만 있을 때) 사용합니다.

```bash
node termux/resolve-and-import.js data/song-lists/파일명.json
```

- 서버가 켜져 있는 상태에서, **다른 창(세션)**에서 실행하세요.
- `.env`의 `YOUTUBE_API_KEY`를 사용합니다 (2번 항목 참고).
- 입력 파일 형식: `[{ "year": 2000, "rank": 4, "artist": "가수", "song": "곡명", "note": "메모(선택)" }, ...]`
- 이미 등록된 곡(제목이 같음)이나 이전 실행에서 처리했던 곡은 자동으로 건너뜁니다.
- **유튜브 Data API는 무료 할당량이 하루 10,000유니트, 검색 1회에 100유니트**라서 하루에 대략 100곡까지만 처리됩니다. 할당량을 다 쓰면 자동으로 멈추고 진행 상황을 저장해두므로, 다음 날 같은 명령을 다시 실행하면 이어서 진행됩니다. 여러 날에 걸쳐 나눠 돌리면 됩니다.

## 참고: 모바일에서 접속이 안 될 때

- 참가자의 휴대폰이 진행자 PC와 **같은 Wi-Fi**에 연결되어 있는지 확인하세요.
- Windows 방화벽이 Node.js의 포트(기본 3000)를 막고 있을 수 있습니다. 방화벽 허용 팝업이 뜨면 "허용"을 눌러주세요.
- 회사/카페 Wi-Fi 등 기기 간 통신이 차단된 네트워크에서는 접속이 안 될 수 있습니다. 개인 Wi-Fi 공유기나 휴대폰 핫스팟을 권장합니다.
